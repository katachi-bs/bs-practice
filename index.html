アプリとして入れる方法

ブラウザのアドレスバーなしで、アプリのように開けます。お使いの端末の手順を開いてください(自動で近いものが開きます)。

パソコン(Chrome / Edge)
  1. このサイトを Chrome か Edge で開きます。
  2. アドレスバーの右端にある「インストール」(パソコンと矢印のマーク)を押します。見当たらないときは、右上のメニュー(Chrome は ⋮、Edge は …)から「キャストして保存して共有」→「ページをアプリとしてインストール」(Edge は「アプリ」→「このサイトをアプリとしてインストール」)を選びます。
  3. 確認が出たら「インストール」を押すと、アドレスバーのない専用ウィンドウで開きます。デスクトップやタスクバーにも置けます。
  4. アイコンを押すたびに、新しいウィンドウで開きます(複数開けます)。
Mac(Safari)
  1. Safari で開き、メニューバーの「ファイル」→「Dock に追加」を選びます(macOS Sonoma 以降)。
  2. 名前を確認して「追加」を押します。Dock のアイコンから、アプリのように開けます。
iPhone / iPad(Safari)
  1. Safari でこのサイトを開きます(ほかのブラウザでは出ないことがあります)。
  2. 画面下(iPad は上)の共有ボタン(□から↑が出るマーク)を押します。
  3. メニューを下へ送って「ホーム画面に追加」を押し、右上の「追加」を押します。
  4. ホーム画面にできたアイコンから開くと、アドレスバーのない全画面で開きます。
Android(Chrome)
  1. Chrome でこのサイトを開きます。
  2. 右上のメニュー(⋮)を押し、「アプリをインストール」(または「ホーム画面に追加」)を選びます。
  3. 確認が出たら「インストール」を押します。ホーム画面やアプリ一覧のアイコンから、全画面で開きます。

※ 更新は自動です(次に開いたときに新しい版になります)。対戦にはインターネットが必要です。入れたあとも、ブラウザ版は今までどおり使えます。

プレイヤー名

▲ 先にプレイヤー名を入力してください。入力すると、下の機能が使えるようになります。

使うデッキを選ぶ

サンプル以外の自作デッキはキャッシュに保存されます。急な削除が不安な場合は、デッキを書き出して文字列を保管してください。ふっかつのじゅもんです。

対戦する

同じ合言葉を入力した2人が自動でマッチングします。ランダムで選ばれた側が、先攻・後攻を選びます。

フリー対戦

合言葉なしで、いま募集中の部屋に入って対戦できます。自分で部屋を作って、相手を待つこともできます。

リプレイ

対戦の記録を、動画のように再生できます(一時停止・巻き戻し・早送り・一手戻る)。直近10件はこの端末に自動で保存されます。書き出して、ほかの人に見せることもできます。

CPUと対戦する

ソロテスト(1台で両側を操作)

1人で両方のプレイヤーを操作して、カードの動きを試せます。流れは対戦と同じです。

開発者モード中(テスト用の項目が表示されています)

管理者メニュー

管理者モード中だけ表示されます。

盤面動画編集エディタ

撮影した動画に合わせて、手札A・手札B・盤面のアニメーションを作る編集画面です。手札から盤面へドラッグして出せます。

バグ・要望報告掲示板

バグを見つけた時や、直してほしいところ・ほしい機能を書いてください。プレイヤー名と内容が保存されて、管理人があとで読めます。

リプレイ

直近の対戦が新しい順に並びます(最大10件)。「書き出し」でファイルや文字列にして保管・共有でき、「取り込む」で他の人のリプレイも見られます。
