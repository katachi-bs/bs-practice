# v36.8.0 (2026/11/19)
- カード画像が2秒たっても表示できないときは、カード名を代わりに表示します。画像の読み込みは続けていて、届いたら画像に切り替わります。読み込みに失敗したときも、間隔をあけて何度も読み込み直します。
- ターンの始まりを、1ステップずつ進める形にしました。スタート → 一拍 → コア(コアが増える動き) → ドロー(一拍おいてカードが手札に入る) → リフレッシュ(一拍おいて回復) → メイン、の順で、動きが終わってから次のステップに進みます。これまでは、スタートの時点で疲労の回復まで終わっていました。
- 重疲労がリフレッシュで疲労に戻るときも、疲労の回復と同じように動かします。
- エンドステップの効果がある場合は、効果と動きがすべて終わってから、相手のターンを始めます。
- 試合の記録(リプレイ)と、CPU同士の学習には影響しません。確認用に tools/pace_test.js を追加しました。
