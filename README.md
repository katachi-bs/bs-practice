## 操作

- 手札のカードを盤面へドラッグ → 召喚・使用(コスト支払いモード)。支払いは自動で選ばれ、足りない=橙・ちょうど=緑・多い=赤で表示されます。
- コアは数字(ソウルコアは★)をドラッグ、またはタップで選択して移動先をタップ。
- ライフはコア素材5個(上3・下2)で表示。通常は触れません(メニューの「ライフの手動操作」でON/OFF)。
- 先攻1ターン目はアタックステップ・第二メインステップを自動で省略します。
- カードをクリックすると、左にカード画像・右に効果文が出ます(`cards/<収録弾>/カード画像/<ID>.jpg` があれば表示、なければ仮画像)。
- アタックステップ(自分の番)では、場のスピリットのボタンが「疲労」ではなく「アタック」になります(アタックできるスピリットは光ります)。
- アタックの流れ: アタック宣言 → アタック時効果 → フラッシュ(受け側から交互。使えるカードは光る。使えなくても「パス」を選べる) → ブロック宣言(ブロック/ライフで受ける) → ブロック時のフラッシュ → BP比べ。
- 効果の対象選択(「BP7000以下を1体破壊」など)は、光っているスピリットをクリックして「決定」。
- コストの支払いは手札の位置の中央にポップアップ。コア(★も含む)をリザーブや場のカードから「支払い」「置くコア」の枠へドラッグし、「決定」で支払います。
- フラッシュの「パス」とブロックの選択は、盤面の中央に大きなボタンで出ます。
- 効果が発動すると、画面中央に「どのカードの何の効果か」を約2秒表示します。ドローは手札に飛び込む動き、回復は縦に回る動き、トラッシュのコアはリザーブへ戻る動きが付きます。
- 支払いでは「★ソウルコアで支払う」ボタンか、ソウルコアを枠へドラッグして指定できます(枠が満杯なら入れ替わります)。
- ステップの自動進行は、左のバーで1つずつ(約0.3秒)点灯して進みます。
- 自動処理に未対応の効果は、ログと通知で「手動で処理してください」と知らせます。
- ソロでは、判断が必要な側(フラッシュの優先権・ブロック・対象選択)へ視点が自動で切り替わります。
- コア以外をクリックすると選択が解除されます(Escでも解除)。
- ログは左の「📜 ログ」で必要なときだけ表示します。ソロ・テスト用の操作は「⚙ メニュー」に入っています。
- 破壊は「ガラスが割れてトラッシュへ」、消滅(コアが0になったスピリット)は「ふわっと消えて粒子がトラッシュへ」の動きです。ライフで受けたときは、ライフのコアが弾けてリザーブへ飛びます。
- コストの支払いは場のコアも使えます。スピリットのコアが0になると、決定後に消滅します。
- ソウルマジックは「ソウルコア1個」(初期設定)か「通常コア」を選べます。
- 対象を指定する効果は、決定するまで効果の文章を表示し続けます。決定前なら「取り消して戻る」で使わなかったことにできます。
- メニューの「ホームに戻る(対戦をリセット)」で、対戦を終えてホームへ戻れます(2回押して確定)。
- 盤面: スピリットは上の段、ネクサスは下の段(相手側は上下が反転)。カードは画面の大きさに合わせて大きくなります。ボイドの表示はありません。
- レベルの色: Lv1=青、Lv2=橙、真界放(ソウルコアでLv2)=紫。効果でBPが上がっているときは緑の▲、下がっているときは赤の▼で表示します(詳細に素のBPとの差が出ます)。
- 盤面でコアを動かしてスピリットのコアが0になるときは、確認のポップアップが出ます(消滅は破壊とは別)。スピリットが抜けると、残りが横へスライドして詰まります。
- 「〜を指定する」効果は、対象が1体しかいなくても、確認のために選んでから決定します。

## 操作の絞り込みとコア入れ替え(テストモードなし)

- コアを動かせるのは「自分のメインステップ/第2メイン」だけ(アタック・バトル・エンド・相手ターンは選択もドラッグも不可、注意文なし)。
- コアが0になったスピリットは、次の操作まで消滅を待つ(確認ポップアップは廃止)。2体にコア1個ずつのときは、一方から他方へ動かし、もう一方へ動かし返して入れ替えられる。自動で入れ替えることはしない。
- 支払いコアも「置くコア」も、リザーブと場のスピリットのコアから選べる(Lv2のマルグリースからの支払い・リザーブ0の召喚に対応)。
- マリガン: 「あなたは先攻です/後攻です」を大きく表示。入れ替え後は4枚まとめてドロー演出。
- リザーブの数字は、コアが飛んで着いた順に1つずつ増える。相手の召喚バナーは短く(4秒)。ターン開始の光は文字の下。

## 効果の自動生成(文言から処理を作る)
`python tools/gen_effects.py` が、取り込み済みカードの本文(`text`)を読み、文言が既知のパターンに完全一致した効果だけを自動処理(`effects`の`ops`)に変換します(`--dry`で集計のみ)。
- 自動で動くもの: 『召喚時/配置時/アタック時/ブロック時/破壊時』の「(コスト・BP・系統・色・疲労状態の条件つき)相手/自分のスピリット・ネクサスを指定して 破壊・手札に戻す・デッキの下へ・回復・疲労・BP±(このターン中/このバトル中、その後BP0なら破壊)・コアをリザーブへ・ボイドからコアを置く」、「N枚ドロー」、「このスピリットをBP+N」「回復/疲労」、「ボイドからコアを自分のトラッシュ/このスピリットへ」、『アタック中/ブロック中』の「このスピリットをBP+N(自分のネクサスがあるなら/系統1体につき)」、『自分/相手のアタックステップ』の「系統を持つ自分のスピリットすべてをBP+N」、マジックの メイン/フラッシュ。
- 条件: 手札の枚数、このターンにライフが減った、自分のネクサスがある、(疲労状態の)〜な自分のスピリットがいる。
- 一致しなかった部分は、スピリットなら文章表示のみ(『…』の見出しつき)、誘発・マジックなら「自動処理に未対応です。手動で処理してください」と案内します。まだ手動のもの: デッキオープン、トラッシュからの回収、起動/増幅/激突/地鳴/操霊/水流/魔述、ターン1回、エンドステップ効果など。
- 手で実装したカード(`unimplemented`の無いもの)は上書きしません。パターンを足したいときは `gen_effects.py` を直して再実行します(未実装のカードだけ作り直し)。
- 対象を選ぶ効果は、盤面のカードを選んで「決定」します(「指定できる」は「指定しない」も選べます)。CPUは自動で選びます。

## 固有効果(第1弾)
- **カード詳細**: 現在のBPの内訳(アタック中+N、このターン中/このバトル中の増減と出どころ)を表示。フィールド上は最終BPのみ。
- **【激突】**: アタック中のスピリットが持つと、ブロックできる(回復状態の)スピリットが相手にいる限り必ずブロックします。「ライフで受ける」ボタンは消え、CPUも必ずブロックします。ブロッカーがいなければライフで受けます。
- **【起動】(メイン/フラッシュ)**: カード詳細に「【起動】フラッシュで使う」ボタンが出ます(使えないときは灰色)。コア支払い・疲労のコストを自動で払い、ターン1回/バトル1回の制限も管理します。中身が自動化できないものは、タイミングとコストのみ処理し、効果は手動で処理する旨を表示します。
- **【増幅】**: 「Nコスト支払う▶系統〜1体につき、このバトル中BP+N」を自動処理。
- 未対応(第2弾): 操霊(トラッシュから召喚)、水流(シンボル追加)、魔述(ノーコストでマジック使用)、地鳴(デッキ破棄と記憶)、コア・ライフ増加のエフェクト。

## 固有効果(第2弾)
- **【操霊】**: 召喚時に、トラッシュの対象スピリットだけを一覧表示。選ぶと通常の召喚と同じコスト支払い画面になります。「発動しない」ボタンつき。
- **【水流】**: フラッシュの起動で、対象スピリットに「このバトル中シンボル+N」を追加。カード上に「シンボル+N」を表示し、ライフを減らす数にも反映します。固有効果のレベル条件を満たさないスピリットは対象にしません(`【水流】を持つ〜`)。
- **【魔述】**: フラッシュの起動で、手札の対象マジックを選んでコストなしで使用(バトル1回)。使わないことも選べます。
- **【地鳴】**: バトル終了時、アタックしたスピリットが残っていれば、相手のデッキの上から指定枚数を破棄。ブロックしたスピリットが相手トラッシュにいれば、そのコスト分を引きます(ライフで受けた/破壊できなかった場合は最大枚数)。破棄は盤面近くに開いてからトラッシュへ。破棄したカードは `G.discards`(ターン・種類・EXか)に記憶します。
- コアやライフが増えるとき、リザーブから飛んでいく演出と「コア+N」「ライフ+N」を表示します。

## 固有効果(第3弾)
- **操霊**: 条件に合うトラッシュのスピリットを、コストを満たしていなくてもすべて表示(コストは通常どおり支払い画面で確認)。
- **ポップアップの移動**: 選択リスト・オープン表示・効果表示・カード詳細は、ドラッグで動かせます(「⠿」の帯、またはマウスなら背景)。選択リストは盤面が見える下側に出ます。
- **エンドステップ効果**: 自分のエンドステップに自動で発動。複数あるときは1つずつ順番を選びます(最後の1つは自動)。
- **トラッシュからの回収**: 対象だけ一覧表示して選ぶと、手札へ飛んでいきます。
- **デッキオープン**: デッキの上からN枚を全員に見える形でオープン。対象以外は白黒。手札に加える/破棄を選び、残りはデッキの下へ「下から1枚目→2枚目」の順にクリックして戻します(破棄の場合は残りも破棄)。戻した順は相手のログにも出ます。
- **地鳴の破棄**: トランプのように1枚ずつ配られて表になり、少し見せてからトラッシュへ払われます(トラッシュの山は演出後に反映)。
- 使える【起動】のあるスピリットは盤面で光ります(押すとカード詳細に起動ボタン)。水流で増えたシンボルは、軽減の計算にも含めます。

## 固有効果(第4弾)
- オープン(デッキの上からN枚)は、相手にも「選んでいるところ」(戻す順番のクリック)がリアルタイムで見えます。
- 条件の追加: 「自分の○シンボルがN個以上」「自分の○のネクサスがN個以上」(アタック中・ブロック中・常時のBP+に対応)。ラベルなしの常時効果にも対応。
- 「自分が(系統/色の)マジックカードを使用した時」(BP+・回復・ドローなど)、「BP比べで相手のスピリットだけを破壊した時」(このスピリット/条件つきの自分のスピリット)を自動処理。
